## SelTranslate 0.0.7

Now based on Handy 0.10.0.

- **File transcription comes from Handy.** Drop an audio or video file into History, or use Transcribe File there. The fork's own Audio file tab is gone.
- **Translation finds a working engine by itself.** If CUDA doesn't start on your computer (usually an NVIDIA driver that is too old), translation switches to Vulkan and tells you so. Without Vulkan it runs on the processor until the next start.
- **Installing CUDA also installs Vulkan** as a spare engine.
- **New look**: a new SelTranslate logo, and the sailboat in place of Handy's mascot.
